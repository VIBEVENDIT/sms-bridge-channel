# 호텔 폰 설치 — AtGangnam SMS Bridge (현장 직원 · 철수님용)

호텔 업무폰(010-5198-5442)에 앱 1개를 설치하면, 그 폰으로 오고 가는 **모든 문자**가 Slack `#lounge-호텔앳강남`에 「앳강남 막내」로 올라오고, 문의에는 정책에 맞춰 자동회신이 나갑니다. PC / Phone Link / Setup.exe 는 더 이상 쓰지 않습니다.

## 0. 확인 (안 되면 멈추고 보고)

- 업무폰이 **Android 8 이상**인가? (설정 → 휴대전화 정보 → 소프트웨어 정보). iPhone이면 설치 불가 — 보고.
- 업무폰은 **항상 충전기에 꽂아 두고** Wi-Fi 또는 LTE 연결.

## 1. 채팅+ 끄기 (필수)

삼성 메시지의 채팅+(RCS)로 온 메시지는 어떤 앱도 읽을 수 없어 Slack에 안 올라갑니다.

삼성 메시지 → ⋮ → 설정 → **채팅+** → 끔. (Google 메시지라면 설정 → RCS 채팅 → 끔)

## 2. 앱 설치

1. 업무폰 브라우저에서 구현 PR에 적힌 APK 링크 열기: `https://github.com/VIBEVENDIT/sms-bridge-channel/releases` → 최신 `android-v…` → `atgangnam-sms-bridge-….apk`.
2. "출처를 알 수 없는 앱" 허용 → 설치. Play 프로텍트 경고가 뜨면 "무시하고 설치".
3. 기본 문자앱은 **바꾸지 않습니다**. 삼성 메시지는 그대로 씁니다.

## 3. 권한 (전부 허용)

앱을 열면 체크리스트가 나옵니다. 모두 초록색이 될 때까지:

1. **SMS**(읽기·수신·보내기), **전화**(번호 확인), **알림** → 허용.
2. 권한이 회색으로 막혀 있으면: 설정 → 애플리케이션 → AtGangnam SMS Bridge → ⋮ → **제한된 설정 허용** → 다시 허용.
3. **배터리 최적화 제외** → 앱의 버튼 누르고 "허용". 삼성: 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 추가.

## 4. 페어링

1. 앱 → 서버 주소는 기본값 그대로.
2. **페어링 코드** 입력 — 철수님이 별도로(비공개) 알려 드립니다. 코드는 1회용이며 48시간 안에 써야 합니다.
3. 상태가 "연결됨 · 마지막 동기화 방금"이면 끝.

## 5. 확인 (QA 기간에는 QA 채널에 올라감)

1. 개인 폰 → 업무폰으로 "감사합니다" → Slack에 `*[문자수신]* :완료:` 1건.
2. 개인 폰 → "체크인 전에 짐 맡길 수 있나요?" → 개인 폰에 자동회신 도착, Slack 스레드에 `*[문자발송]*`.
3. Slack 스레드에 `>> 테스트 답장` → 개인 폰에 도착.
4. 업무폰 삼성 메시지로 개인 폰에 직접 답장 → Slack 같은 스레드에 `*[문자발송]* 호텔폰 직접`.

전체 QA 목록: [ACCEPTANCE.md](./ACCEPTANCE.md) §2.

## 6. 운영 규칙

- 직원 답장은 Slack 스레드 `>> 내용` 또는 업무폰에서 직접 — 둘 다 Slack에 남습니다.
- 접두어 없는 스레드 글은 내부 메모(발송 안 됨).
- 끝난 건은 parent에 `:완료:` reaction, 다시 확인 필요하면 `:loading:` reaction.
- 앱을 강제 종료하거나 권한을 끄지 마세요. 업무폰이 15분 이상 오프라인이면 Slack에 경보가 뜹니다.

## 7. PC 브리지 제거 (go-live 후)

프런트 PC: `%LocalAppData%\HotelAtGangnamSmsBridge\uninstall.ps1` 우클릭 → PowerShell에서 실행.
